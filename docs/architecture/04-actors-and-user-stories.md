# Actors

-   Customer Support Agent
-   Service Engineer
-   Service Manager
-   Salesforce Administrator

# User Stories

1.  As a Support Agent, I want to register customer assets.
2.  As a Support Agent, I want to create service requests.
3.  As a Manager, I want to assign engineers.
4.  As an Engineer, I want to view my assigned work.
5.  As an Engineer, I want to update job progress.
6.  As an Engineer, I want to record maintenance visits.
7.  As an Engineer, I want to record replaced parts.
8.  As a Manager, I want to monitor SLA breaches.
9.  As a Manager, I want maintenance reports.
10. As an Admin, I want secure access using permission sets.
