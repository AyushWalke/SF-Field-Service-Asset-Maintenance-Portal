# Naming Conventions

## Object Prefix

Use **FSAM\_** for every custom object.

Examples:

-   FSAM_Customer_Asset\_\_c
-   FSAM_Service_Request\_\_c
-   FSAM_Maintenance_Visit\_\_c

## Field Example

-   Warranty_End_Date\_\_c
-   SLA_Due_Date\_\_c
