# Dynamic Actions

## Purpose

Improve the Lightning Experience by displaying only the most relevant actions on each record page.

## Configured Actions

- Edit
- Delete
- Clone

### Service Request

- Edit
- Delete
- Clone

### Maintenance Visit

- Edit
- Delete

### Engineer Assignment

- Edit
- Delete

### Service Part

- Edit
- Delete
- Clone

### Part Replacement

- Edit
- Delete

## Notes

- Dynamic Actions enabled on all record pages.
- No conditional visibility rules implemented.
