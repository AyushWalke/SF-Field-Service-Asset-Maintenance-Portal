# FSAM Portal Lightning App

## Purpose

Provides a centralized workspace for managing customer assets, service requests, maintenance visits, engineer assignments, spare parts, reports, and dashboards.

## Navigation

- Home
- Accounts
- Customer Assets
- Service Requests
- Maintenance Visits
- Engineer Assignments
- Service Parts
- Part Replacements
- Reports
- Dashboards

## Notes

- Standard Navigation
- Desktop and Mobile supported
