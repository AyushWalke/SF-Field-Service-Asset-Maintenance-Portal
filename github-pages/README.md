# FSAM GitHub Pages Portfolio

This folder is a static portfolio/demo site generated from the Salesforce DX repository. It is designed to document the project for recruiters/interviewers; it does **not** host the Salesforce runtime.

## Publish

The repository includes `.github/workflows/deploy-pages.yml`, which deploys `github-pages/` to GitHub Pages when pushed to `main`.

After pushing, enable GitHub Pages using **GitHub Actions** as the source if the repository has not already been configured.
